## 2699 and 2700 — COMPLETE 2026-09-17 (a fork of the orchestrator's session)

**Contract 2699.** Given a gateway, when anything asks for a model's published measurements, the gateway answers from a snapshot baked into its binary at build time, overlaid figure by figure by a catalogue the user's own Artificial Analysis key produced; an absent or unparseable overlay leaves the baked copy standing, and no figure is invented.

**Contract 2700.** Given a Pane session, when the system block is built, the `agent` declaration names the models this session's gateway actually serves, strongest first by intelligence, unmeasured models listed last by name rather than as a zero, bounded at twenty with a count of the rest, and says the figures are Artificial Analysis' and that a higher index costs more; `[agents] mode = "off"` lists nothing and says subagents are refused; `pinned` names the pinned model and still lists the alternatives.

**Why the gateway and not Glasshouse.** Pane read Artificial Analysis by shelling out to `glasshouse analysis`, which made an optional component load-bearing for a Pane feature (memory `three-component-architecture`). The numbers now live where the models do. `glasshouse.rs::intelligence` and the `/model` picker are untouched and still use their path.
