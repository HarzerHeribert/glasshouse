## The three things that are always true here

1. **Phase −1 is a hard gate.** A packet must show every claimed input has
   a producer, a caller, a propagation path and an observing consumer in
   *current* code. `scripts/validate_round.py` enforces it and is free.
2. **A box is ticked only when its evidence entry says so**, and evidence
   means a test that fails when the behaviour is removed — not code that
   exists and not a worker that said ACCEPT.
3. **Workers correct their packets and are usually right.** Thirteen
   consecutive rounds, as of batch 45. Read a worker's PACKET ERRORS
   section before its results.
