# Security

Please report a vulnerability **privately**, not in a public issue:
use [Report a vulnerability](https://github.com/HarzerHeribert/glasshouse/security/advisories/new)
on the Security tab.

Especially welcome: anything that could leak a provider key or login, let a
model step outside the permissions Pane grants it, or tamper with an update or
install.

You will get a reply within a few days. Once a fix is released, the advisory is
published with credit to you, unless you would rather not be named.

Only the newest release is supported: `pane update` moves you to it.
